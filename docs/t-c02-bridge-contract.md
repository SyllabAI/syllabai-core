# T-C02 GLM-OCR → Core Bridge Contract

Status: implementation contract; no corpus-wide ingestion.

## Source

`SyllabAI/syllabai-parser` main @ `9eb35ab` is the verified source. The bridge consumes the parser's canonical JSON and extracted QP/MS drafts. It must not re-parse Markdown or invent a second document model.

## Pipeline

`parser canonical QP JSON` + `parser canonical MS JSON`
→ core `CanonicalDocumentValidator`
→ core `ContentIngestionService.ingest(...)`
→ deterministic chunks
→ existing assessment T-011 ingestion for the extracted QP/MS draft
→ `SUGGESTED` paper/question/version/scheme/points
→ teacher validation gate
→ explicit existing `DocumentEmbeddingService` invocation after approval.

## Required invariants

1. Source checksums remain the idempotency key for canonical documents.
2. Canonical `documentId` remains the deterministic parser identity; no new ID is generated by the bridge for canonical documents.
3. QP/MS publication code, paper code, log number, session and provenance remain visible in the imported data.
4. Curriculum placement and prerequisites are never inferred by this bridge.
5. QP/MS mismatches are preserved as review findings; no silent merge or correction.
6. Expired GLM-OCR signed image URLs remain unavailable. No bytes are fabricated. Local assets retain `img:<sha256>` identity.
7. Bridge re-runs are safe: existing canonical rows are reported as duplicates and existing assessment entities are not duplicated.
8. Embedding is never implicit. The bridge may stop after chunking.
9. Imported assessment content remains non-servable while `SUGGESTED`.
10. The controlled verification set is exactly the six files in `SyllabAI/Past-Papers/GLM-markdown-sample` (three QP/MS pairs).

## Test shape

A fixture-driven Spring integration test should exercise one pair through the real application context and Testcontainers/portable Postgres where available, then repeat the same import and assert no duplicate canonical or assessment rows. Assert chunk provenance contains canonical element IDs. Assert an unvalidated question cannot be served through the existing `ServableQuestionSpec` gate.

## Out of scope

Do not process the 2,700+ PDF corpus, do not change the 768-dimensional embedding index/model, and do not bypass teacher validation.
